## ✨ Características

- Galería **antes / después** de trabajos realizados
- Carrusel de reseñas de clientes
- Showcase de videos de servicios
- **Mapa interactivo** del área de cobertura (Leaflet)
- Contenido administrable desde un archivo JSON, sin tocar código
- **SEO**: `sitemap.xml`, `robots.txt` y metadatos
- Diseño responsive y despliegue continuo en **Netlify**

## 🛠️ Tecnologías

Vue 3 · Vue Router · Vite · Leaflet · CSS3 · Netlify

## 🚀 Instalación local

```bash
npm install
npm run dev
```
